## フェルマーの小定理

フェルマーの小定理を利用して法的逆元(逆数)を求めるアルゴリズム

a^(p-1) ≡ 1 (mod p) であることから、
a * a^(p-2) ≡ 1 (mod p) となり、a^(p-2) が a の法的逆元となる。

[fermat](./fermat/)

### 実装例

- [] C
- [] Python
- [x] Haskell
